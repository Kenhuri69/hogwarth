## Sections à remplir (par personnage)
> ❓ À détailler, pour chacun : caractère en 3 traits, voix/manière de parler,
> motivation, lien avec la trame, et éventuel **arc personnel** ou réplique
> signature. Les personnages originaux ont surtout besoin de fond.

### Modèle de fiche
```
### <Nom>
- Maison / rôle :
- Personnalité (3 traits) :
- Motivation (pourquoi descend-il/elle ?) :
- Voix (ton, tics de langage) :
- Lien à la trame / aux Maisons :
- Arc personnel (optionnel) :
- Tagline (✅ existe déjà pour chacun dans data.js) :
```

## Questions de cadrage
- Les héros ont-ils des **dialogues propres** (barks en exploration/combat) ou
  restent-ils muets façon avatar ?
- Les **originaux** (Manon n'est pas jouable, mais Céleste/Iris/etc. le sont)
  ont-ils des liens entre eux (une promo, une confrérie « Garde de l'Aube »
  évoquée dans le code) ?
