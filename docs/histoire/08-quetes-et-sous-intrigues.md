- **Potions** (Slughorn) : déblocage de recettes de brassage.
- Easter eggs évoqués dans le code : **Reliques de la Mort**, **Salle sur
  Demande**, **libération d'un elfe de maison**.

## Sections à remplir
### 8.1 Typologie des quêtes
> ❓ À détailler : principales (jalonnent la trame) vs secondaires (saveur,
> récompenses) vs répétables (farm). Objectifs : `item` / `kill`.

### 8.2 Fiches de quête (modèle)
```
### <Quête>
- Donneur / lieu :
- Accroche narrative :
- Objectif (mécanique) :
- Étapes / rebondissements :
- Récompense (xp/or/objet/sort) + récompense narrative :
- Liens (PNJ, autres quêtes, lore) :
```

### 8.3 Sous-intrigues à développer
> ❓ À détailler : donner à chaque arc (Élara, Lux Aeterna, Chasse Sans Tête,
> easter eggs) son propre sous-markdown si le contenu grossit.
